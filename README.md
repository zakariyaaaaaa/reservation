# Reservation Management System

A modern PHP-based reservation management system with integrated Stripe payment processing.  
This application allows users to manage reservations and process secure online payments using Stripe.

---

# 🚀 Features

- Reservation management
- Online payment integration with Stripe
- Responsive design
- Secure payment handling
- Clean project structure
- Composer dependency management
- Easy local deployment using XAMPP

---

# 📁 Project Structure

```bash
C:.
├── config
├── css
├── img
├── public
└── vendor
````

## Folder Description

| Folder    | Description             |
| --------- | ----------------------- |
| `config/` | Configuration files     |
| `css/`    | Stylesheets             |
| `img/`    | Images and assets       |
| `public/` | Public accessible files |
| `vendor/` | Composer packages       |

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/zakariyaaaaaa/reservation.git
```

---

## 2️⃣ Open Project Folder

```bash
cd reservation
```

---

## 3️⃣ Install Composer Dependencies

```bash
composer install
```

---

## 4️⃣ Configure Environment Variables

Create a `.env` file in the root directory:

```env
STRIPE_SECRET_KEY=your_secret_key
STRIPE_PUBLIC_KEY=your_public_key
```

---

# ▶️ Running the Project

Move the project to:

```bash
xampp/htdocs/
```

Start:

* Apache
* MySQL

Then open:

```bash
http://localhost/reservation/public
```
